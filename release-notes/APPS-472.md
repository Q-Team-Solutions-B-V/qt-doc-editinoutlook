## Improved error messages for missing report settings and security hardening

When sending documents via Edit in Outlook, a clear error message is now shown when no report selection is configured, instead of an unexpected error. The PDF viewer now only accepts secure (HTTPS) URLs. Delete permissions on the PDF Viewer setup have been removed from all permission sets.
